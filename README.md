# 📄 PaperNews

最新のAI論文を日本語で手軽に読めるWebアプリです。

arXivから最新論文を取得し、Gemini APIを利用して要約・専門用語解説を生成します。

---

## ✨ 主な機能

- 📚 最新AI論文を毎回ランダムに5件表示
- 🏷️ カテゴリ別フィルタ
- 🤖 AIによる日本語要約
- 💡 「読む理由」の生成
- 📖 専門用語の解説
- ⭐ ブックマーク機能
- 🔗 arXivへのリンク

---

## 使用技術

- Next.js
- React
- TypeScript
- Gemini API
- arXiv API

## 開発背景

英語論文は読み始めるハードルが高く、
「まず内容をざっくり知りたい」という課題を解決するために制作しました。

AI要約・専門用語解説を通して、
論文に興味を持つきっかけを提供することを目的としています。
