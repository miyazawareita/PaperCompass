# 📄 PaperCompass

最新のAI論文を、読む前に「自分に読めそうか」「読む価値があるか」を判断するための情報系学生向けのWebアプリです。

arXivから最新論文を取得し、Gemini APIを利用してAI要約・重要キーワード解説・推定難易度を生成します。
論文の概要や必要な前提知識を把握し、興味を持った論文をarXivで読むきっかけを提供します。

---

## ✨ 主な機能

- 📚 最新AI論文を毎回ランダムに5件表示
- 🏷️ カテゴリ別フィルタ
- 🤖 AIによる日本語要約
- 💡 「読む理由」の生成
- 🎓 AIによる推定難易度表示（情報系学部4年生基準）
- 📖 重要キーワードの解説
- ⭐ ブックマーク機能
- 🔗 arXivへのリンク

## 開発背景

arXivには毎日多くの論文が投稿されていますが、

* タイトルだけでは内容が分からない
* 自分の知識で読める論文か判断しづらい
* 英語論文を読み始めるハードルが高い

といった課題があります。

PaperCompassは、AIによる要約・重要キーワード解説・推定難易度・読む理由の生成を通して、「その論文を読む価値があるか」「自分の知識で挑戦できるか」を判断するための情報を提供することを目的としています。
